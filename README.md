# 📜 Gerador de Certificados

Projeto simples para geração de certificados usando Angular, Bootstrap e HTML.

## Tecnologias

- Angular 20
- Bootstrap 5
- HTML5
- TypeScript

## Como Executar

```bash
# Clone o repositório
git clone https://github.com/allyciaroxha/gerador-certificado.git
cd gerador-certificado

# Instale as dependências
npm install

# Execute o projeto
ng serve
